1.Install Dependencies

MERN stack with three modules (frontend, backend, and admin), you need to install dependencies separately for each module.

Frontend Module:
-------------------------------------------------------------------
STEP 1: Navigate to the Frontend Folder -> cd frontend

STEP 2: Install the Frontend dependencies -> npm install

STEP 3: Run using Command -> npm run dev 

Frontend: http://localhost:5173 → For users to book appointments
--------------------------------------------------------------------

Backend Module:
--------------------------------------------------------------------
STEP 1: Navigate to the Backend Folder -> cd backend

STEP 2: Install the Backend dependencies -> npm install

STEP 3: Run using Command -> npm run server

Backend: http://localhost:4000 → API (Postman or browser access)
--------------------------------------------------------------------

Admin Module:
--------------------------------------------------------------------
STEP 1: Navigate to the Admin Folder ->? cd admin

STEP 2: Install the admin dependencies -> npm install

STEP 3: Run using Command -> npm run dev

Admin Panel: http://localhost:5174 → For managing appointments and doctors
